# Unfold UI — legal pages

Public privacy policy and terms of service for the **Unfold UI** Android launcher, served via GitHub Pages at **https://unfoldui.mygig.life**.

- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `index.html` — landing page linking both
- `CNAME` — custom domain for GitHub Pages

Unfold UI collects no data and has no internet permission; the privacy policy reflects that. If a future app version adds any data collection, update `privacy.html` and the Google Play Data safety form before that version ships.
